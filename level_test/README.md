# 水平自测：3 关

## 目的

不是考你，是**定位你「能看懂」和「能写」之间的缝在哪**。

你目前的状态：能跟着跑通代码、能看懂每行注释，但还没独立写过。这三关每一关对应一个具体能力，做完我会从你提交的东西里判断你在哪个阶段。

## 三关分别对应什么

| 关 | 测什么 | 不通过说明 |
|---|---|---|
| 第 1 关 | 纯 Python 基础：列表 / 字典 / 循环 / 条件 / f-string 是否真会写 | 基础还没长在自己身上 |
| 第 2 关 | 读代码找 bug + 嵌套取值 + `.get()` + `try/except` | 看得懂结构，但不会写安全取值 |
| 第 3 关 | 填空补全一次 API 调用骨架 | 记得住「发请求」的完整流程 |

## 怎么交

1. **一次只做一关**，不要三关一起做。
2. 做完把「你写的代码 + 运行结果（或报错原文）」发给我。
3. 卡住超过 30 分钟就停，把写出来的部分和卡在哪发我——**带具体报错**，不要只说"不会"。
