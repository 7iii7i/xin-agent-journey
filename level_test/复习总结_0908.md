## 二、今天新钉的 2 个概念

### 1. `if __name__ == "__main__":` = 门卫
- **白话**：自己运行这个文件 → 下面那段执行；被别人 `import` → 不执行
- 你原话："自己运行这个代码执行下面的，被 import 不执行" → 准
- **为什么要有**：同一个文件既能当主程序直接跑，也能当工具箱被别人借用，两不耽误。
  （回想 `week01/day1_class_chatbot.py` 的 `chat_loop()`，一 import 就弹输入把你卡住，加了门卫才安静）

### 2. 8203（零宽空格 U+200B）
- **是什么**：屏幕上看不见的字符，混进代码会让 Python 报 `unexpected indent` 之类莫名错误
- **怎么查**：用 Python 在原始字节扫 `e2 80 8b`（3 秒出真相），别靠肉眼
- **浏览器/HTML 里**会显示成 `&#8203;`（同一个东西的另一种写法，不是真文字）
- **钉死**：文件里看到莫名其妙的缩进报错，先怀疑它
