# f-string 小抄

> 一份随时可查的速查表。`week01/notes/` 下与 f-string 相关的所有疑问都回到这里。

## 一、一句话定义

**f-string = format string，Python 3.6 引入的「字符串里嵌变量」的写法。** 在字符串前加一个 `f`，里面的 `{}` 大括号里就可以放任意 Python 表达式，运行时会被替换成它的值。

```python
name = "忻"
print(f"你好 {name}")       # 输出：你好 忻
print(f"2 + 2 = {2 + 2}")   # 输出：2 + 2 = 4
print(f"今天是 2026 年")     # 没用 f-string 也可以，没有变量要嵌
```

## 二、语法只有 3 条规矩

**规矩 1：字符串前必须有 `f` 这个字母。**

```python
print("你好 {name}")        # 错：{} 没被替换，原样打印
print(f"你好 {name}")        # 对：name 替换进去
```

`f` 可以大写 `F`，效果一样。**忘了写 f，是初学者最常犯的 f-string 错误。**

**规矩 2：`{}` 里写的是「表达式」，不是「字符串」。**

```python
age = 28
print(f"我 {age} 岁")        # 对
print(f"我 {age + 1} 岁")   # 对：可以算
print(f"我 {"age"} 岁")      # 错：大括号内不该再加引号
```

把 `{}` 里想象成**一段独立的 Python 代码**，它跑出来的结果会塞进字符串。

**规矩 3：外层用单引号，内层就用双引号；外层双引号，内层就用单引号。**

```python
name = "北京"
print(f'我去过 {name}')       # 对：外单内无
print(f"我去过 {name}")       # 对：外双内无（最常用）
print(f'我去过 "{name}"')     # 对：外单内双
print(f"我去过 "{name}"")     # 错：双引号套双引号，Python 懵了
```

## 三、最常用的 6 种「格式说明符」

`{}` 里可以加 `:` 后跟说明符，控制**怎么显示**。

| 写法 | 作用 | 例 | 输出 |
|---|---|---|---|
| `{x}` | 直接打印 | `f"{3.14159}"` | `3.14159` |
| `{x:.2f}` | 保留 2 位小数 | `f"{3.14159:.2f}"` | `3.14` |
| `{x:>10}` | 右对齐，宽度 10 | `f"{'hi':>10}"` | `        hi` |
| `{x:<10}` | 左对齐，宽度 10 | `f"{'hi':<10}"` | `hi        ` |
| `{x:^10}` | 居中，宽度 10 | `f"{'hi':^10}"` | `    hi    ` |
| `{x:,}` | 千位分隔 | `f"{1234567:,}"` | `1,234,567` |
| `{x:.1%}` | 百分比 1 位小数 | `f"{0.856:.1%}"` | `85.6%` |

`:.2f` 是最常用的——价格、分数、概率都靠它。`:>` / `:<` / `:^` 在打印表格时尤其好用。

## 四、和 `print(..., ..., ...)` 的区别

这是个你刚刚踩过的坑，值得专门记一下：

```python
name = "忻"
n = 28

# 写法 A：print 逗号分隔
print(name, n, "岁")
# 输出：忻 28 岁      ← 中间有空格（Python 自动加的）

# 写法 B：f-string
print(f"{name} {n}岁")
# 输出：忻 28岁       ← 中间没空格（你控制的）
```

**多变量拼字符串时，f-string 是默认选项。** 逗号写法只在调试时（多个变量分开打印）用。

## 五、什么时候不用 f-string

- 字符串里没有任何变量要嵌 → 不用加 `f`，加不加都一样
- Python 3.5 及更老的版本不支持 → 你用 3.13，没这个顾虑
- 要做复杂格式化（多次复用同一格式） → 用 `format()` 或 `Template`，但 95% 的情况 f-string 都够

## 六、一道题测一下自己（答案在底部）

不用跑，**在脑子里回答**：下面这段会输出什么？

```python
city = "玉环"
pop = 65
score = 0.8765
print(f"【{city:^6}】人口 {pop:>5}万  准确率 {score:.1%}")
```

<details>
<summary>点开看答案</summary>

```
【  玉环  】人口    65万  准确率 87.7%
```

分解：
- `玉环` 居中在 6 个字符宽里，两边各 2 个空格 → `  玉环  `（共 6 个字符宽）
- `65` 右对齐在 5 个字符宽里 → `    65`（前面 4 个空格）
- `0.8765` 保留 1 位小数的百分比 → `87.7%`

如果全对，f-string 你已经掌握了。如果哪部分模糊，回头看对应的格式说明符。

## 七、相关小坑

- **`f` 写漏**：报错是「正常显示 `{}`」，不是报错——这种 bug 最难发现
- **大括号里又用同种引号**：SyntaxError，但错误信息提示的位置经常**不是你真的错的那行**，往上找 1-2 行
- **嵌套 f-string**（f-string 里还有 f-string）：可以但很难看，**别用**，临时变量拆出来更清楚
