## 今天搞懂的

一次 API 调用 = 同一个数据不停变形态：

```
str（你的想法）
  → list[dict]（messages）
  → dict（payload，加模型/温度）
  → str（requests 偷偷 json.dumps，网络只能传文本）
  → dict（response.json() 还原）
  → str（从嵌套里掏出 content）
```

最容易卡人的地方：`requests.post(url, json=xxx)` 里的 `json=` 参数
**自动帮你做了 json.dumps()**。没写 dumps 却能用，就是它在背后干的。
