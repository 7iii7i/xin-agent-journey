② Agent 大脑（week03 · 终端脚本，毕业版的核心） 必须懂

这是"你写的 Agent 连接大模型的模板"——大脑。它在 week03/w3_agent_full.py，自己跑（python w3_agent_full.py）不能联网。下面抓最该懂的四块：

import os, json
from openai import OpenAI

# 1. 连接大模型 —— 【理解+会改】换家/换 key/换 base_url 改这
client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    base_url="https://api.deepseek.com",
)

# 2. 真实函数：模型调工具时真正干活的 —— 【必须自己写】agent 的真本事
def 加法(num1, num2):
    return f"{num1} + {num2} = {num1 + num2}"

# 3. 工具清单：告诉模型"你有个 add 可用"（name/参数必须英文）—— 【必须自己写】
工具清单 = [{"type":"function","function":{
    "name":"add","description":"计算两个数字相加",
    "parameters":{"type":"object","properties":{
        "num1":{"type":"number"},"num2":{"type":"number"}},
        "required":["num1","num2"]}}}]

历史 = []   # 【理解】跨轮记忆就存在这

# 4. while 多步推理（大脑核心）—— 【必须懂】
while 轮次 < 最大轮次:
    resp = client.chat.completions.create(model="deepseek-chat",
        messages=历史, tools=工具清单, tool_choice="auto")
    回复 = resp.choices[0].message
    if 回复.tool_calls:          # 模型决定调工具 → 执行 → 继续循环
        历史.append(回复)
        for 调用 in 回复.tool_calls:
            函数名 = 调用.function.name
            参数 = json.loads(调用.function.arguments)   # 把文字菜单翻成真字典
            if 函数名 == "add":
                结果 = 加法(参数["num1"], 参数["num2"])  # 【必须自己写】真执行
            历史.append({"role":"tool","tool_call_id":调用.id,"content":str(结果)})
        continue
    else:                        # 模型不调工具、给最终答案 → 跳出
        print("模型：" + 回复.content)
        break
client 连接 理解+会改 真实函数/工具清单 必须自己写 历史=记忆 理解 while+tool_calls 大脑核心 必须懂

🔑 控制流要点（你今晚抠透的）：if 调工具→continue 继续；else 不调→break 出口。最终答案永远从 else 出，但它是"调完工具后这轮决定不调了"才到。首轮就不调工具也走同一个 else（while 只跑 1 次），是正确设计不是 bug。json.loads 必须把模型发来的"文字版参数"还原成真字典，才能 参数["num1"] 取值。

③ 毕业版：给大脑套 FastAPI 外壳（week04 · 联网接口） 重点

week04 的 api_service.py 把上面的 while 大脑封装成 跑_agent() 函数，外面套 @app.post("/ask")。比本卡 ② 多了两样：① BaseModel 收客户端消息（有外部输入才有它）② 顺手把问答存进 SQLite（第 3 层持久化）。

from fastapi import FastAPI, BaseModel
from openai import OpenAI
import os, json, sqlite3
from datetime import datetime

client = OpenAI(api_key=os.environ["DEEPSEEK_API_KEY"], base_url="https://api.deepseek.com")

# 加法 / 工具清单 / 跑_agent(while 大脑) 与 ② 完全相同，直接复用，不重复写

app = FastAPI()

class 提问体(BaseModel):        # 有外部输入→用 BaseModel 收【理解+会改】
    question: str

@app.post("/ask")               # 门牌：POST + /ask【理解+会改】
def ask(提问: 提问体):
    try:
        答案 = 跑_agent(提问.question)   # 调大脑算出答案
        存问答(提问.question, 答案)      # 第3层：存进数据库
        return {"answer": 答案}          # 【必须自己写】把结果递出去
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"服务内部出错：{e}")
app=FastAPI() / @app.post 理解+会改 BaseModel 收消息 理解+会改 return {"answer":...} 业务逻辑 必须自己写

📌 和 ② 的区别就一行：② 的 print 是直接打印给终端；③ 的 return {"answer": 答案} 是把答案装进 JSON 信封发回客户端。其余 app=FastAPI()、@app.post、BaseModel 全是脚手架（理解+会改即可）。api_service.py 末尾还有 if __name__=="__main__": uvicorn.run(...) 把"怎么起服务"写进代码，不用记 uvicorn 命令。

④ 装进集装箱：Dockerfile（week04） 理解为主·会改端口/依赖

把整间店（FastAPI + Agent 大脑 + 数据库）装进集装箱。真实文件 week04/Dockerfile，比纯 FastAPI 多了中文编码兜底（否则中文会炸）。

FROM python:3.13-slim                       # 基础系统【理解+会改：换版本】
ENV PYTHONIOENCODING=utf-8 LANG=C.UTF-8 LC_ALL=C.UTF-8   # 中文兜底
WORKDIR /app                                # 店内工作目录
COPY requirements.txt .                      # 先搬依赖清单（利用缓存）
RUN pip install --no-cache-dir -r requirements.txt         # 装 fastapi/uvicorn/openai
COPY . .                                    # 搬代码
EXPOSE 8000                                 # 声明监听 8000（房间号）
CMD ["python","-m","uvicorn","api_service:app","--host","0.0.0.0","--port","8000"]  # 开门
FROM 版本 会改 依赖清单/端口 会改 CMD 启动 uvicorn 理解为何在这

🔗 "容器 8000" = 容器里 uvicorn 监听的端口（房间号），由 CMD --port 8000 决定。-p 本机:容器 第二个数必须=它。改了监听 9000 就写 -p 8000:9000。镜像才是打包的产品（死），容器是它跑起来的活实例——别混。

⑤ 一条命令起 + 自测（week04） 记死口诀

真实文件 week04/docker-compose.yml 把"build + run -p + 传密钥"写成一个文件。先设好密钥，再一条命令起：

# 终端先设密钥（Windows）
set DEEPSEEK_API_KEY=sk-xxxx
# 进 week04 目录，一条命令起（含 build + run -p 8000:8000）
docker compose up --build

口诀："-p 前面本机、后面容器"。跑起来后：你自己开 http://localhost:8000/docs 自测（发 POST 给 /ask）；同 WiFi 用你笔记本局域网 IP:8000 也能试；公网陌生人进不来（路由器 NAT 挡着）。要全网进，把容器 run 在云服务器上。

🌐 整合闭环：week03 大脑（②） + week04 FastAPI 外壳（③） + week04 Dockerfile（④） + docker compose up（⑤） = "我写的 Agent 连接大模型的模板，通过接口接给别人用（别人 POST 我的 /ask），并且我自己 localhost:8000 自测。" 这就是"FastAPI 包 Agent 成 API 服务"的完整形态。

  • □ 必须自己写：真实函数（如 加法）、工具清单、sys_prompt 人设、return 里的业务逻辑

  • □ 必须懂：while+tool_calls+历史 三件套；if 调工具/else 给答案 的分支；json.loads 还原参数
