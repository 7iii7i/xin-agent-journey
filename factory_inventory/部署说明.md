# 工厂库存查询 Agent —— 部署说明

一个能跑在工厂电脑上的「自然语言查库存」小系统：浏览器打开网页，用大白话问"螺丝还有多少""给钢板入库 100 公斤"，AI 自动查/改库存数据库。

## 一、三种运行方式（挑一种）

### 方式 A：朋友厂一键启动（最简单，推荐给不懂技术的厂里）
1. 把整个 `factory_inventory` 文件夹拷到工厂电脑
2. 双击 `启动.bat`
3. 浏览器打开 http://localhost:8002

> 前提：工厂电脑装了 Python 3.11 并勾选了"Add to PATH"。
> 没装 Python 也能用 —— 见下方"进阶：打包成 exe"。

### 方式 B：本地直接跑（开发用）
```bash
pip install -r requirements.txt
python main.py
# 打开 http://localhost:8002
```

### 方式 C：Docker 部署（简历亮点：已容器化、可上云）
```bash
docker build -t factory-inventory .
docker run -d -p 8002:8002 --name fi factory-inventory
# 打开 http://localhost:8002
```
或用 compose（自动读 .env）：
```bash
docker compose up -d --build
```

## 二、上云让外网也能访问（简历写"已部署供真实工厂使用"）
- 把镜像推到任意云（阿里云/腾讯云轻量应用服务器、Railway、Render 等）
- 云上用环境变量 `DEEPSEEK_API_KEY` 注入 key（**不要把 key 写死进公开镜像**）
- 云防火墙放行 8002 端口，给朋友一个公网网址即可

## 三、进阶：打包成 exe（工厂电脑完全不用装 Python）
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole main.py
# 生成的 dist/main.exe 拷到工厂电脑双击即跑（需把 index.html / .env 放同目录）
```
> 这一步按需再做，v1 先用方式 A 足够试用。

## 四、数据说明
- 库存存在 `factory.db`（SQLite 文件），首次运行自动建表并塞 10 条示例数据
- 想换成工厂真实库存：删掉 `factory.db`，改 `main.py` 里 `_塞种子()` 的数据，或后续做"Excel 导入"功能

## 五、安全提醒（写简历时要提的"工程意识"）
- `.env` 里是 DeepSeek key，**别提交到公开代码仓库**
- 当前任何人打开网页都能查/改库存，真上线建议加简单登录（后续迭代）
