## 规则（我自己定的）

1. **GitHub 提交不断。** 连续 3 天空白 = 我在滑坡，当天必须补上。
2. **单个问题卡超过 45 分钟**就换策略：查文档 / 问人 / 先跳过。硬耗是自我感动。
3. **前 8 周限制使用 Cursor / Claude Code。** 基础语法和调试能力必须长在自己身上。
4. **代码是自己敲的，不是复制的。** 抄十遍不如自己憋出来一遍。
5. **每个项目必须有量化指标。** 没数字的项目只是 demo，不是作品。
