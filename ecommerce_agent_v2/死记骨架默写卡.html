① async def ... yield 生成器

📍 位置：agent.py → async def 跑_agent(历史) 完整函数

async def 跑_agent(历史: list):
    消息 = [{"role": m["role"], "content": m["content"]} for m in 历史]
    消息.insert(0, {"role": "system", "content": SYSTEM})
    轮次 = 0
    while 轮次 < 10:
        轮次 += 1
        # ① 工具轮：非流式，干净拿工具+参数
        resp = await client.chat.completions.create(
            model=配置.MODEL, messages=消息,
            tools=注册表.清单(), tool_choice="auto",
        )
        回复 = resp.choices[0].message
        if 回复.tool_calls:
            消息.append(回复)
            for 调用 in 回复.tool_calls:
                函数名 = 调用.function.name
                参数 = json.loads(调用.function.arguments or "{}")
                结果 = await 注册表.调用(函数名, 参数)
                消息.append({"role": "tool", "tool_call_id": 调用.id, "content": str(结果)})
            continue
        # ② 最终轮：流式，逐 token 推（打字机）
        stream = await client.chat.completions.create(
            model=配置.MODEL, messages=消息, stream=True,
        )
        async for chunk in stream:
            d = chunk.choices[0].delta
            if d.content:
                yield d.content
        return
    yield "⚠️ 达到最大轮次"
核心：async def 让函数能「等」；yield（非 return）让答案一字一字「流」出。两者配合 = 异步生成器。
⚠️ 易手滑点：
1. 写 async def 忘了加 await → 「异步」形同虚设。
2. 把 yield d.content 写成 return → 打字机变一次性。
3. 流式对象用 async for chunk in stream:，不是普通 for。

② SSE 推送那行

📍 位置：main.py 第 41–64 行（/ask 接口 + 事件流() 完整块）

@app.post("/ask")
async def ask(提问: 提问体):
    await 会话库实例.追加(提问.session_id, "user", 提问.question)
    历史 = await 会话库实例.取历史(提问.session_id)

    async def 事件流():
        完整 = ""
        try:
            async for token in 跑_agent(历史):
                完整 += token
                yield f"data: {json.dumps(token, ensure_ascii=False)}\n\n"
        except Exception as e:
            日志.exception("Agent 执行出错")
            yield f"data: {json.dumps('⚠️ 服务出错：' + str(e), ensure_ascii=False)}\n\n"
        finally:
            if 完整.strip():
                await 会话库实例.追加(提问.session_id, "assistant", 完整)

    return StreamingResponse(事件流(), media_type="text/event-stream")
  • yield：推出这一小段，不等全部（打字机关键）。
  • data: ：SSE 协议固定前缀，浏览器靠它识别「这是一条数据」。
  • json.dumps(token, ensure_ascii=False)：转 JSON 安全串；ensure_ascii=False 保住真实中文。
  • \n\n：SSE 消息分隔符（两个换行 = 一条推完）。
⚠️ 易手滑点：
1. 漏写 data: 前缀 → 前端解析不了。
2. 漏掉第二个 \n → 流不结束，页面卡住。
3. 忘了 ensure_ascii=False → 中文变 \u5e2e\u60a8 乱码。

③ aiosqlite 套路

📍 位置：db.py → 会话库 类（建表 / 追加 / 取历史，aiosqlite 套路全集）

class 会话库:
    def __init__(self, 库名=配置.会话DB名):
        self.库名 = 库名

    async def 初始化(self):
        async with aiosqlite.connect(self.库名) as db:
            await db.execute("""
                CREATE TABLE IF NOT EXISTS turns (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    session_id TEXT, role TEXT, content TEXT, time TEXT
                )
            """)
            await db.commit()

    async def 追加(self, session_id, role, content):
        async with aiosqlite.connect(self.库名) as db:
            await db.execute(
                "INSERT INTO turns (session_id, role, content, time) VALUES (?, ?, ?, ?)",
                (session_id, role, content, datetime.now().strftime("%Y-%m-%d %H:%M:%S")),
            )
            await db.commit()

    async def 取历史(self, session_id, 上限=20):
        async with aiosqlite.connect(self.库名) as db:
            async with db.execute(
                "SELECT role, content FROM turns WHERE session_id=? AND role IN ('user','assistant') ORDER BY id ASC LIMIT ?",
                (session_id, 上限),
            ) as cur:
                行 = await cur.fetchall()
        return [{"role": r[0], "content": r[1]} for r in 行]
核心：async with aiosqlite.connect 开库（用完自动关）；每个会「等」的操作前加 await；写操作末尾加 await db.commit()。商品库写法完全相同。
⚠️ 易手滑点：
1. 写操作漏 await db.commit() → 数据没真存，查不到。
2. 用同步 sqlite3.connect 忘了换 aiosqlite → 异步里直接卡线程。
3. SQL 用 ? 占位符 + 参数元组 (...,)，别直接拼字符串（防注入）。
