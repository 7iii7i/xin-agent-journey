① FastAPI 三件套 🔴 死记

脚手架：公司(app) + 收数据的碗(BaseModel) + 接口(@app.post) + 回(return)。

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()                     # ① 公司

class 提问体(BaseModel):            # ② 收数据的碗
    问题: str

@app.post("/ask")                   # ③ 接口
def ask(提问: 提问体):
    return {"answer": "..."}        # ④ 回

易手滑：① BaseModel 拼错 ② @app.post 的 @ 和括号 ③ return 缩进要进函数里 ④ 字段类型 str/int 别漏

② Dockerfile 七行 🔴 死记

脚手架：造箱子说明书。七行业务 + 三行 UTF-8（防中文乱码）。

FROM python:3.13-slim
ENV PYTHONIOENCODING=utf-8
ENV LANG=C.UTF-8
ENV LC_ALL=C.UTF-8
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python","api_service.py"]

易手滑：① WORKDIR 拼成 WORKDIE ② COPY . . 是两个点 ③ requirements.txt 逗号变点 ④ CMD 里空格不能少 ⑤ EXPOSE 端口要对

③ Agent 三件套（while 大脑） 🔴 死记

业务逻辑：历史列表(喂模型) + while(心跳) + if tool_calls(看要不要调工具)。

def 跑_agent(问题):
    历史 = [{"role":"user","content":问题}]
    while 轮次 < 10:
        resp = client.chat.completions.create(
            model="deepseek-chat", messages=历史,
            tools=工具清单, tool_choice="auto")
        回复 = resp.choices[0].message
        if 回复.tool_calls:
            历史.append(回复)
            for 调用 in 回复.tool_calls:
                函数名 = 调用.function.name
                参数 = json.loads(调用.function.arguments)
                if 函数名 == "add":
                    结果 = 加法(参数["num1"], 参数["num2"])
                    历史.append({"role":"tool","tool_call_id":调用.id,"content":str(结果)})
            continue
        return 回复.content

易手滑：① completions 少 s ② tool_choice 拼成 tools_choice ③ 判断用 == 不是 = ④ role:"tool" 单数 ⑤ str(结果) 用 () 不是 [] ⑥ for 行漏冒号

④ SQLite 四步 🔴 死记

业务逻辑：连接→执行→保存/取→关闭。写操作(INSERT/DELETE)必须 commit。

import sqlite3
conn = sqlite3.connect("test.db")
cur = conn.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS t (id INTEGER, name TEXT)")
cur.execute("INSERT INTO t VALUES (1, '小明')")
conn.commit()                      # 写操作必须保存
rows = cur.fetchall()              # 读：取全部
conn.close()

易手滑：① sqlite3 拼成 sqliete3 ② fetchall 漏 () ③ 写了不 commit ④ DELETE 放循环里被反复调→只剩最后一行 ⑤ 重复运行会追加（删 .db 或循环前清一次）
